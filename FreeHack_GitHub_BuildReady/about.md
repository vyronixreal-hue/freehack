# FreeHack

FreeHack is a custom Geometry Dash utility menu inspired by the multi-column layout shown in the reference screenshot.

## Included interface

- MegaHack-style multi-column window
- Categories for Auto, Bypass, Creator, Cosmetic, Level, Status, Universal, Cheat Safety, Display, Utility, Screenshot, Speedhack, and Replay
- Searchable-looking grouped option layout
- Toggle-style controls
- Persistent Geode settings foundation
- F6/open-key foundation
- Clean FreeHack branding

The project is intentionally structured so individual gameplay features can be implemented as separate hooks without rewriting the menu.
